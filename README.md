# Zepto Data & AI Platform (Capstone Submission)

A unified end-to-end Data & AI Platform comprising a scraping data pipeline, predictive customer analytics modeling, and a grounded GenAI support assistant service.

---

## 1. Environment Setup

All modules run under a unified Python 3.10+ environment using dependencies listed in `requirements.txt`.

```bash
# Clone Repository
git clone <your-repo-link>
cd zepto-ai-platform

# Create & Activate Virtual Environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install Dependencies
pip install -r requirements.txt
